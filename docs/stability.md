# 안정성 방어 시연 체크리스트

계획 Task 19 Step 1. 이상 입력을 넣었을 때 앱이 멈추지 않고 안내를 보여 주는지 확인한다.

## 확인 환경

- 날짜: 2026-11-02, 브랜치 `feature/copy-tone`(core 문구 '~해요' 통일 반영 후)
- Streamlit 1.66.1, 로컬 실행. 데스크톱 Chrome(headless, 1100×900)을 Playwright로 조작해 캡처했다.
- 인식기 있는 화면: `RECOGNIZER=mock .venv/bin/streamlit run app.py`
- 키 없음 화면: `RECOGNIZER=gemini`, `GEMINI_API_KEY` 빈 값
- 여행은 시작 화면의 "저장한 정산 파일 불러오기"로 넣었다(참석자 민수·지영·철수, 2026-10-10~10-12, 각자 결제).
- Mock 인식기는 이미지 해시로 `tests/fixtures/receipts/`의 JSON 하나를 고른다. 그래서 "영수증 아닌 사진"은 `not_receipt.json`이 골라지는 이미지를 만들어 넣었다. 실제 AI가 사진을 영수증이 아니라고 판단하는지는 이 시연으로 확인하지 않는다.
- 캡처: `docs/screenshots/stability/`

모든 항목에서 Streamlit 예외 화면(traceback)은 나오지 않았다.

### 발견한 점

- 7a: 계획의 기대 문구는 "이미지 파일이 아닙니다"였지만, 실제로는 Streamlit 업로더가 확장자로 먼저 막아서 앱 코드까지 오지 않는다. 막는 것은 맞지만 안내가 영어이고 툴팁이라 눈에 잘 띄지 않는다. 업로더의 `type` 제한을 풀고 앱에서 직접 안내할지는 정하지 않았다.

## 키 준비 후 확인

| 항목 | 입력 | 기대 화면 | 확인 결과 |
|---|---|---|---|
| 실제 AI의 영수증 아닌 사진 판단 | 풍경·음식 사진 | "영수증이 아니어서 제외했어요." | 키 준비 후 확인 |
| 잘못된 API 키 | 형식은 맞지만 틀린 키 | "AI 키가 맞지 않거나 쓸 권한이 없어요. 앱 설정의 GEMINI_API_KEY를 확인해 주세요." SDK 원문(JSON)과 키 값은 보여 주지 않음 | 통과(2026-11-02, 가짜 키로 실제 Gemini 호출). 처음 확인 때는 영어 JSON 원문이 그대로 나와 고쳤다 |
| 하루 한도 초과(429, PerDay) | 무료 등급에서 하루 20장 넘게 업로드 | 재시도 없이 "오늘 쓸 수 있는 AI 횟수를 다 썼어요. 내일 다시 읽을 수 있어요." 여러 장이면 "a.jpg 외 n장: …" 한 줄 | 실제 키에서 하루 한도 429를 확인했다. 안내 문구는 실제 응답 모양으로 만든 단위 테스트로 확인 |
| 분당 한도(429)·서버 과부하(503) | 짧은 시간에 여러 장 업로드 | 1, 2, 4초 간격 재시도 후 "AI 요청이 한꺼번에 몰렸어요. 1분쯤 뒤에 다시 올려 주세요." 또는 "AI 서버가 바빠서 응답하지 않아요. …" | 실제 키에서 503 재시도 후 통과를 확인했다. 분당 한도는 단위 테스트로 확인 |
| 주소 좌표 변환 실패 | 주소·상호로 찾을 수 없는 영수증 | `core/geocode.py`가 None을 돌려주고 그 건만 지도에서 빠진다. 정산은 영향 없음. 지도 화면은 `feature/map` 작업이라 그 머지 후 확인 | 키 준비 후 확인(`KAKAO_REST_API_KEY`) |
