# 안정성 방어 시연 체크리스트

계획 Task 19 Step 1. 이상 입력을 넣었을 때 앱이 멈추지 않고 안내를 보여 주는지 확인한다.

## 확인 환경

- 날짜: 2026-11-02, 브랜치 `feature/copy-tone`(core 문구 '~해요' 통일 반영 후)
- Streamlit 1.66.1, 로컬 실행. 데스크톱 Chrome(headless, 1100×900)을 Playwright로 조작해 캡처했다.
- 인식기 있는 화면: `RECOGNIZER=mock .venv/bin/streamlit run app.py`
- 키 없음 화면: `RECOGNIZER=gemini`, `GEMINI_API_KEY` 빈 값
- 여행은 시작 화면의 "저장한 정산 파일 불러오기"로 넣었다(참석자 민수·지영·철수, 2026-10-10~10-12, 각자 결제).
- Mock 인식기는 이미지 해시로 `tests/fixtures/receipts/`의 JSON 하나를 고른다. 그래서 "영수증 아닌 사진"은 `not_receipt.json`이 골라지는 이미지를 만들어 넣었다. 실제 AI가 사진을 영수증이 아니라고 판단하는지는 이 시연으로 확인하지 않는다.
- 캡처: `docs/screenshots/stability/`

모든 항목에서 Streamlit 예외 화면(traceback)은 나오지 않았다.

### 발견한 점

- 7a: 계획의 기대 문구는 "이미지 파일이 아닙니다"였지만, 실제로는 Streamlit 업로더가 확장자로 먼저 막아서 앱 코드까지 오지 않는다. 막는 것은 맞지만 안내가 영어이고 툴팁이라 눈에 잘 띄지 않는다. 업로더의 `type` 제한을 풀고 앱에서 직접 안내할지는 정하지 않았다.
