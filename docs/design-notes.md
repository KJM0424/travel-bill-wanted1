# 화면 디자인 방향

## 목표
목업이 아닌 실제 서비스처럼 보이는 모바일 우선 웹. 친구들과 여행을 마치고 휴대폰 한 손으로 영수증을 올리고, 누가 누구에게 얼마를 보낼지 받아 보는 화면.

서비스 이름은 Travill(트래빌). 이름·소개 문구는 `ui/branding.py` 한 곳에서만 정한다.

## 색
흰 바탕과 진한 본문 위에 강조색은 하나만 쓴다.

| 이름 | hex | 쓰는 곳 | 대비 |
|---|---|---|---|
| 바탕 | `#FFFFFF` | 화면 배경 | |
| 면 | `#F2F4F6` | 입력칸, 송금 메시지, 정산 요약 | |
| 본문 | `#191F28` | 제목·본문 | 흰 바탕 16.6:1 |
| 보조 글자 | `#6B7684` | 시간·결제자, 날짜 머리줄 | 흰 바탕 4.6:1 |
| 선 | `#E5E8EB` | 목록 구분선, 카드 테두리 | |
| 여권 초록 | `#17654C` | 로고, 주요 버튼, 진행 막대, 받을 돈 | 흰 바탕 7.0:1, 흰 글자 7.0:1 |
| 오류 빨강 | `#C2362B` | 오류 문구만 | 흰 바탕 5.5:1 |

강조색 고르기:
- 토스 파랑(`#0064FF`, `#3182F6` 계열)은 쓰지 않는다. 이 앱은 토스 송금 링크를 보내므로 토스 공식 화면으로 오인되면 안 된다.
- 여행에서 출발했다. 예전 초록 여권의 짙은 초록을 골라 "여행"과 "돈이 들어온다(받을 돈)"를 함께 떠올리게 했다.
- 흔한 기본값 점검: SaaS 파랑·보라, 크림+테라코타, 검정+형광 강조를 피했다. 밝은 청록이 아니라 어둡고 무게 있는 초록이라 흰 글자를 올려도 AA를 넘는다.

## 서체
- Pretendard(OFL) 하나. `static/fonts/PretendardVariable.woff2`를 앱이 직접 내려주고 테마 `fontFaces`로 연결한다. 라이선스 원문은 같은 폴더의 `Pretendard-LICENSE.txt`.
- 크기 위계: 본문 16px, 소제목 18px, 화면 제목 24px, 시작 화면 큰 문구 28px, 정산 총액 32px. 보조 글자는 14px 안팎.
- 굵기: 본문 500, 제목 700, 정산 총액 800.
- 금액은 자릿수 폭을 맞춘 숫자(`tabular-nums`)로 보여 위아래 금액을 비교하기 쉽게 한다.
- 송금 메시지도 같은 서체로 보여 준다. 고정폭 서체는 개발 화면처럼 보여서 쓰지 않는다.

## 레이아웃
- 콘텐츠 최대 너비 480px, 가운데 정렬. 390px 화면에서도 가로 스크롤 없이 좌우 여백 20px.
- 사이드바 없음. 화면 위는 앱 상단 막대처럼 왼쪽 "이전", 오른쪽 작은 "2/4"만 둔다. 진행 막대는 테스트 화면처럼 보여서 뺐다.
- 화면마다 주요 버튼 하나를 아래에 고정한다(정산 시작하기, 다음, 정산하기, 정산 파일 저장하기).
- 시작: 큰 문구 두 줄과 세 단계 안내(영수증 올리기 → 안 간 사람 빼기 → 송금 메시지). 순서가 있는 과정이라 번호를 붙였다.
- 설정: "어떤 여행이었나요?"(이름, 가는 날·오는 날 한 줄)와 "누구와 갔나요?"(이름 입력 → 총무를 이름 칩으로 고름)로 나눴다.
- 업로드: 점선 테두리의 큰 사진 칸. Streamlit 기본 영어 문구는 CSS로 "사진 고르기", "여러 장을 한 번에 골라도 돼요"로 바꿨다. 읽는 중에는 "14장 중 7장 읽었어요".
- 검토(가장 크게 바꿈): 결제마다 입력칸을 다 펼친 양식 대신 은행 앱 거래 내역처럼 날짜별 목록으로 바꿨다.
  - 맨 위에 정산할 결제 건수와 합계, 날짜 머리줄에 그날 합계.
  - 한 줄: 분류 아이콘, 상호, "15:42, 민수 결제", 금액, "수정".
  - 참석자는 줄 아래 이름 칩으로 바로 고친다. 빠진 사람은 회색 취소선이라 한눈에 보인다.
  - 금액·날짜·주소·결제자·정산에서 빼기는 "수정"을 눌러 그 줄 안에서 펼쳐 고친다. 화면 테스트(AppTest)에서 `st.dialog` 안의 버튼을 누를 수 없어 수정 창 대신 펼침으로 했다.
  - 경고(합계 불일치, 여행 기간 밖, 중복 의심)는 해당 줄에 작은 주황 글자로, 중복은 맨 위에 한 번만 알린다. 내부 번호(#1, #2)와 "사진에서 읽음" 표시는 없앴다.
- 정산 결과: 맨 위에 영수증 한 장처럼 아래가 톱니 모양인 요약(여행 이름·기간, 총액, 결제 건수, 인원, 1인 평균). 이 앱에서 디자인으로 힘을 준 곳은 이 하나다. 그 아래 "보낼 돈"(보내는 사람 → 받는 사람, 금액, 메시지, 메시지 복사), "사람별 정산", "표로 보기", 여행 경로 지도.
- 여행 경로 지도: 결제 순서대로 여권 초록 원에 흰 번호를 단 마커와 같은 색의 움직이는 선(AntPath). 교통비·직접 추가한 결제는 뺀다. 카카오 키가 없으면 지도 대신 안내, 조회가 전부 실패하면 "위치를 불러오지 못했어요", 일부만 못 찾으면 지도 아래에 상호명을 나열한다.

## 문구
- "~해요" 말투, 짧게. 화면 제목은 질문이나 안내 한 문장("누구와 여행했나요?", "이렇게 나누면 돼요").
- 설명조 긴 문장을 줄였다. 예: 중복 경고 "'스타벅스 애월점 (#1 10/11 15:02)'와 …는 금액이 같고 10분 안에 결제했어요…" → "스타벅스 애월점 15:02 결제가 두 번 있어요."
- 인식 실패 안내의 괄호·마침표 겹침(".).")을 "s11.png: 읽지 못했어요. AI 호출 한도를 넘었어요. … 직접 추가해 주세요."로 고쳤다.

## 개발 요소 숨김
- `client.toolbarMode = "minimal"`로 Deploy 버튼과 개발자 메뉴를 숨긴다.
- 제목 옆 링크 아이콘은 `anchor=False`, 마크다운은 `anchors=False`로 끈다.
- "인식기: mock" 같은 개발 정보는 보이지 않는다. `RECOGNIZER=mock`일 때만 작은 "체험 모드" 배지를 보인다.

## CSS
테마 설정으로 안 되는 것만 `ui/layout.py`에서 우리가 붙인 key 클래스에 적용한다(`.st-key-page`, `row_`, `ico_`, `rt_`, `part_`, `edit_`, `day_head_`, `upload_box`).
- 좌우 여백 20px, 한글 줄바꿈 `keep-all`, 금액 숫자 폭 맞춤.
- 검토 목록의 줄 구분선, 아이콘 원, 펼친 수정 칸 배경, 빠진 사람 칩 취소선(`aria-pressed="false"`).
- 업로드 칸 모양과 한국어 문구, 정산 요약의 톱니 모양, 시작 화면 세 단계 목록.
- Streamlit 내부 구조(`data-testid`)에 기대는 규칙이 있어 Streamlit을 올리면 화면을 다시 확인해야 한다.

## 상태·접근성 점검(ui-ux-pro-max 체크리스트)
- 빈 화면: 결제가 없으면 영수증 올리기·직접 추가를 안내한다. 결제가 없을 때는 업로드 화면의 "영수증 읽기"가 주요 버튼이 된다.
- 로딩: 인식 중에는 "14장 중 7장 읽었어요" 진행 막대.
- 오류: 무엇이 문제인지와 돌아갈 곳(확인 화면으로 돌아가기, 직접 입력)을 함께 둔다. 업로드 제외 안내는 한 상자에 모은다.
- 대비: 본문·버튼·강조·오류 글자 모두 AA(4.5:1) 이상(위 표).
- 키보드 포커스: Streamlit 기본 포커스 링을 유지하고, 복사 버튼에도 `:focus-visible` 테두리를 줬다.
- 좁은 화면: 390px에서 가로 스크롤 없음(scrollWidth 390 확인), 주요 버튼 높이 44px 이상, 2열 입력은 좁은 화면에서 한 열로 쌓인다.

## 남은 한계
- 업로드 칸의 한국어 문구는 CSS 가상 요소로 덮어쓴 것이라, 화면 낭독기는 원래 영어 버튼 이름을 읽을 수 있다.
- 검토 화면의 줄 전체 누르기는 투명 버튼을 줄 위에 덮어 만들었다(아래 2차 개편). 화면 낭독기는 이 버튼을 "{상호} 펼치기/접기"로 읽는다.

## 2차 개편 (2026-11-02): 화면마다 한 가지에 집중
- **설정:** 질문 하나에 카드 하나("어디로 다녀왔나요?", "누구와 함께 갔나요?", "어떻게 정산할까요?", "○○님 계좌를 알려 주세요"). 날짜를 고르면 "2박 3일", 이름을 적으면 "3명"과 이름 칩이 바로 보여 입력이 제대로 들어갔는지 알 수 있다. 여행 이름은 "(선택)"으로 필수가 아님을 밝혔다.
- **검토:** 줄에는 상호·금액·시각·결제자·함께한 사람 요약("3명 모두", "A, C")만 둔다. 줄을 누르면 참석자 칩과 수정 칸이 펼쳐지고 다시 누르면 접힌다. 참석자 칩을 줄마다 늘 보여 주던 방식은 결제가 많으면 화면이 길어져 바꿨다. 대신 줄 요약에 함께한 사람을 적어 펼치지 않아도 빠진 사람을 알 수 있다.
- **정산:** "보낼 돈 / 사람별 정산 / 여행 돌아보기"를 위쪽 버튼으로 하나씩 본다. 처음엔 가장 할 일이 분명한 "보낼 돈". 지도는 그 탭을 열 때만 위치를 찾으므로 카카오 호출도 필요할 때만 생긴다.
- **글씨:** 화면 제목 22px, 카드 질문 18px, 본문 16px, 입력칸 이름 15px 굵게, 보조 설명 14px. 입력칸 글자는 16px로 두어 휴대폰에서 자동 확대되지 않게 했다. 글꼴은 Pretendard 그대로.
- 캡처: `docs/screenshots/app-feel/`

## 3차 다듬기 (2026-11-02): 앱처럼 느껴지게
- **위쪽 바:** 뒤로 아이콘(44px 누름 영역, 화면 읽기 프로그램에는 "이전"), 가운데 화면 이름(여행 정보·영수증 올리기·결제 내역·정산 결과), 오른쪽 단계 수. 바로 아래 4칸 진행 막대. 양옆 폭을 같게 두어 이름이 정확히 가운데에 온다.
- **다시 그릴 때 흐려지지 않게:** Streamlit은 누를 때마다 화면을 흐리게(data-stale) 다시 그려 웹 페이지처럼 느껴졌다. 흐림을 끄고 바뀐 곳만 바뀌게 했다.
- **누르는 반응:** 버튼·칩은 누르는 순간 98%로 살짝 작아지고, 결제 줄은 바탕이 잠깐 진해진다. 펼친 수정 칸은 0.18초 동안 내려오며 나타난다. "동작 줄이기" 설정이면 모두 끈다.
- **아래 고정 버튼:** 위에 1px 경계선, 아이폰 아래 여백(safe-area)만큼 띄운다.
- **체험 모드 안내:** AI를 부르지 않는다는 사실 그대로 안내한다(전에는 Gemini 안내가 나왔다).
- 캡처: `docs/screenshots/app-polish/`
