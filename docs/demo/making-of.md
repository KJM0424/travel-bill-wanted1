# 시연 영상 제작 과정

결과물은 `docs/demo/travill-demo.mp4`다. 1분 55초, 1920×1080, 한국어 음성과 자막이 들어 있다.

사람이 직접 화면을 녹화하지 않고 두 스크립트로 만들었다.
- `scripts/record_demo.py`: 앱을 정해진 순서대로 조작하며 녹화한다.
- `scripts/make_demo_video.py`: 녹화한 것을 자르고 음성·자막을 넣어 편집한다.

대본만 고치면 같은 방식으로 다시 만들 수 있다.

## 1. 계획

- **녹화 방식:** 스크립트가 앱을 정해진 순서대로 조작하며 자동으로 녹화한다. 실수 없이 여러 번 다시 찍을 수 있다.
- **인식 모델:** 내 맥북의 로컬 모델(Ollama `qwen3-vl:8b-instruct`)로 영수증을 읽는다.
  - Gemini 무료 하루 한도(20회)를 쓰지 않고 몇 번이든 다시 찍기 위해서다.
  - 배포판은 Gemini API를 쓴다. 영상 위쪽에 이 사실을 적었다.
- **장면:** 가이드 기준인 1~3분 안에 "핵심 흐름과 방어 장면"이 들어가도록 14개로 정했다.

| 순서 | 장면 | 보여 주는 것 |
|---|---|---|
| 1 | 시작 | 네 단계 안내 |
| 2 | 여행 정보 | 이름, 날짜, 3명, 총무 계좌(카카오뱅크) |
| 3 | PDF 안내 | 방어: 이미지가 아닌 파일은 받지 않음 |
| 4 | 영수증 올리기 | 영수증 6장과 바다 사진 1장 |
| 5 | 인식 중 | 로컬 모델이 읽는 동안(빨리 감기) |
| 6 | 인식 끝 | 방어: 영수증이 아닌 사진 제외 |
| 7 | 결제 내역 | 날짜별 정리 |
| 8 | 결제 고치기 | 저녁 결제자를 민호로 바꾸기(결제자가 여러 명인 여행) |
| 9 | 빠진 사람 빼기 | 카페 결제에서 민호 빼기 |
| 10 | 보낼 돈 | 송금 메시지, 계좌 복사 |
| 11 | 사람별 정산 | 낸 돈과 부담할 돈 |
| 12 | 여행 돌아보기 | 날짜별 경로와 요약 |
| 13 | 다시 보기 | 자동차가 결제 순서대로 경로를 달림 |
| 14 | 끝 | "영수증은 AI가 읽고, 확인은 사람이 한다" |

## 2. 준비물

- **영수증:** 생성 영수증 6장(`eval/images/synthetic/` s04 국수, s08 카페, s05 마트, s02 호텔, s07 생선구이, s09 우도샌드)
- **영수증이 아닌 사진:** `docs/demo/sea.jpg`. Pillow로 그린 바다 그림이다.
- **잘못된 파일:** `docs/demo/itinerary.pdf`. 일정표 PDF다.
- **대본:** `docs/demo/script.md`
  - 장면마다 `## 장면 | 카드 제목 | 카드 설명` 한 줄과 읽을 문장 한 줄로 적었다.

## 3. 녹화 (`scripts/record_demo.py`)

- **화면 크기:** 휴대폰 크기(430×932) 브라우저에서 앱을 연다.
- **조작:** 입력, 클릭, 파일 올리기를 순서대로 한다.
- **터치 자국:** 녹화 영상에는 마우스 커서가 보이지 않는다. 그래서 누르는 곳에 초록색 터치 자국을 그린다.
- **장면 시각:** 장면이 시작할 때마다 영상 안 시각을 `marks.json`에 기록한다.
- **녹화 횟수:** 모두 4번 녹화했다.
  1. 날짜 칸에서 멈춤. Streamlit 1.66의 날짜 칸이 연·월·일이 따로 입력되는 칸이었다. 그래서 연도 칸을 누르고 숫자를 치게 바꿨다.
  2. 은행이 "카카오"로 들어감. 입력한 글자에서 Enter를 누르면 그 글자가 새 항목으로 들어갔다. 그래서 목록의 "카카오뱅크"를 누르게 바꿨다.
  3. 성공.
  4. 화면 문구를 "나눌 몫"에서 "부담할 돈"으로 바꾼 뒤 다시 녹화했다.

## 4. 편집 (`scripts/make_demo_video.py`)

- **자르기와 빨리 감기:** 장면 시각 기록으로 영상을 장면별로 자른다. 인식을 기다리는 구간만 빨리 감는다(약 90초 → 9초). 빨리 감은 배수는 화면에 적는다.
- **음성:** 장면마다 대본 문장을 음성으로 만든다. 음성이 장면보다 길면 그 장면의 마지막 화면을 잠깐 멈춰 길이를 맞춘다.
- **화면 구성:** 1920×1080 화면에 세 가지를 배치한다.
  - 왼쪽: 휴대폰 화면
  - 오른쪽: 장면 설명 카드
  - 아래: 자막
- **글자:** 설치된 ffmpeg에 자막·글자 기능(libass, drawtext)이 없었다. 그래서 카드와 자막은 Pillow로 이미지를 그리고, 장면 시간에 맞춰 영상 위에 겹쳤다.

## 5. 확인과 수정

- **프레임 확인:** 장면 시각마다 프레임을 뽑아 화면, 카드, 자막이 맞는지 눈으로 확인했다(`docs/demo/frames/`).
- **파일 검사:** ffprobe로 길이, 해상도, 소리 트랙을 확인했다.
- **확인하며 고친 것**
  - **휴대폰 화면이 왼쪽 위 4분의 1에만 찍힘:** Playwright는 화면 배율과 상관없이 CSS 픽셀 크기로 녹화한다. 녹화 크기를 화면 크기와 같게 하고, 편집에서도 그 영역만 쓰게 했다.
  - **자막이 어두운 띠 밖으로 넘침:** 줄을 나누는 너비를 띠 안쪽 너비에 맞췄다.
  - **고칠 것이 없는 "금액 고치기" 장면:** 프롬프트 v2가 돌아간 영수증의 금액을 맞게 읽었다. 그래서 고치는 척하는 장면 대신 실제 수정인 "결제한 사람 바꾸기"로 바꿨다.

## 6. 음성 고르기

- **처음 음성:** macOS 기본 음성 Yuna는 기계 같은 느낌이 났다.
- **견본 비교:** 같은 문장으로 Yuna와 Microsoft 신경망 음성 세 가지(SunHi, InJoon, Hyunsu) 견본을 만들어 들어 봤다.
- **선택:** 현수(`ko-KR-HyunsuMultilingualNeural`)로 정했다. 녹화는 다시 하지 않고 편집만 다시 했다.
- **인터넷:** 음성을 만들 때만 필요하다. 만든 음성은 mp4 소리 트랙에 들어가서, 재생할 때는 인터넷이 필요 없다.

## 쓴 도구

| 도구 | 용도 | 비용·설치 |
|---|---|---|
| Claude Code | 계획, 녹화·편집 스크립트 작성, 결과 확인 | 사용 중 |
| Streamlit 앱(로컬, `RECOGNIZER=ollama`) | 녹화 대상 | 프로젝트 |
| Ollama + `qwen3-vl:8b-instruct` | 영상 속 영수증 인식(로컬 모델) | 무료 |
| Playwright + Chromium | 브라우저 자동 조작과 화면 녹화 | 무료. 앱과 분리된 환경에 설치 |
| ffmpeg / ffprobe | 장면 자르기, 빨리 감기, 화면 합성, 음성 섞기, MP4 만들기, 검사 | 무료 |
| Pillow | 설명 카드·자막 이미지, 휴대폰 테두리, 바다 그림 | 무료 |
| edge-tts | Microsoft 신경망 음성 "현수" | 무료, 키 필요 없음. 대본이 Microsoft 서버로 전송됨 |
| macOS `say`(Yuna) | 처음 쓴 음성. 지금은 오프라인 대안 | macOS 기본 |
| Apple SD Gothic Neo | 카드·자막 글꼴 | macOS 기본 |

## 다시 만드는 방법

1. **Playwright와 edge-tts 설치:** 앱과 다른 환경에 설치한다.
   ```bash
   python -m venv videoenv
   videoenv/bin/pip install playwright edge-tts
   videoenv/bin/python -m playwright install chromium
   ```
2. **앱 실행:** 로컬 모델 모드로 켠다(Ollama가 켜져 있어야 한다).
   ```bash
   RECOGNIZER=ollama .venv/bin/streamlit run app.py --server.port 8630
   ```
3. **녹화:** 장면 시각은 `docs/demo/raw/marks.json`에 남는다. 녹화 원본(`docs/demo/raw/`)은 커밋하지 않는다.
   ```bash
   videoenv/bin/python scripts/record_demo.py --out docs/demo/raw
   ```
4. **편집:** 인터넷이 없으면 `--tts say`로 macOS Yuna를 쓴다.
   ```bash
   .venv/bin/python scripts/make_demo_video.py --edge-tts videoenv/bin/edge-tts
   ```
